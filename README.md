## Descripción de la aplicación

Esta aplicación web fue desarrollada utilizando React y Vite, la aplicación consume una API pública de Game of Thrones para mostrar frases de diferentes personajes de la serie.
Cada frase muestra información obtenida directamente desde la API, como el nombre del personaje, la frase y la casa a la que pertenece.

## Componentes desarrollados

- App
- Header
- SearchBar
- QuoteCard
- Footer

## Datos utilizados de la API

La aplicación utiliza los siguientes datos:

- Frase del personaje
- Nombre del personaje
- Casa del personaje
- Identificador del personaje

## Funcionalidad de búsqueda o filtro

La aplicación permite buscar frases utilizando el nombre del personaje, el usuario puede escribir el nombre de un personaje y la aplicación filtra los resultados mostrados.

## Funcionalidad adicional implementada

La aplicación cuenta con dos funcionalidades adicionales:

- Mostrar u ocultar los detalles de cada frase.
- Obtener nuevas frases mediante el botón "Nueva frase".
